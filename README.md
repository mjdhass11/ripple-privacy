# Ripple — privacy policy

The public copy of the privacy policy for the Android game **Ripple**, served at
<https://mjdhass11.github.io/ripple-privacy/> via GitHub Pages.

This repo is public only so the policy has a reachable, non-geofenced URL, as
Google Play requires. The game itself is developed elsewhere and carries the
same text in-app under Settings → Privacy policy. **Change both together.**
